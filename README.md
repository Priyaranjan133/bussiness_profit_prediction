# Business Profit Prediction (Streamlit)

    pip install -r requirements.txt
    streamlit run app.py

- Page 1 **Dashboard**: metrics (R², MAE, MSE), charts, dataset, test predictions
- Page 2 **Predictor**: enter R&D / Administration / Marketing spend -> estimated profit, scenario comparison
- Use your own data: upload a CSV in the sidebar (columns: R&D Spend, Administration, Marketing Spend, Profit)
- Deploy: push this folder to GitHub, then create the app on share.streamlit.io (main file: app.py)
